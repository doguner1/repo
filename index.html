CarSplit (CarPlay Dual-Screen)

by @doguner • Tweaks

Run two independent applications (e.g. Navigation + YouTube/Music) simultaneously side-by-side in Split-Screen mode on Apple CarPlay. True dual touch input, 1-tap clock switch, and seamless Settings integration.

📦 How to Install

  1. Tap Add to Sileo or Add to Zebra above (or copy this repository URL into your package manager sources).
  2. Wait for sources to refresh and locate CarSplit in the package list.
  3. Install the tweak and perform a quick respring.
  4. Open Settings → CarSplit on your phone and switch Enable CarSplit to ON (disabled by default for safety).
  5. Plug into your car, open your desired apps, and tap the status bar clock to cycle split-screen layouts!
