CarSplit (CarPlay Dual-Screen)

Run two independent applications (Navigation + YouTube/Music, etc.) simultaneously side-by-side in Split-Screen mode on Apple CarPlay.

  • Fully compatible with Dopamine 2 Rootless (iOS 15.0 – 15.8.x)
  • One-tap Split-Screen toggle directly from the CarPlay Status Bar Clock
  • Settings app integration with dynamic Enable/Disable control (Disabled by default)
  • Integrated one-tap diagnostic reporting for cross-vehicle compatibility
  • Full localization support in 10 languages
  • Dual independent touch input and window management
Add to Sileo Add to Zebra

How to Install

  1. Tap Add to Sileo above (or copy this repo URL into your package manager sources).
  2. Refresh sources and install the CarSplit package.
  3. Open Settings → CarSplit and toggle Enable CarSplit ON.
  4. Connect to your car's CarPlay screen and tap the status bar clock icon to enter split-screen mode.
